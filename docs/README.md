# docs/

Coloca aqui el/los PDF(s) con la informacion sobre la que quieres que el
chatbot responda. Puedes añadir varios PDFs a la vez.

Al arrancar `chatbot.py`, el indice (troceado + embeddings) se genera o se
actualiza automaticamente si detecta PDFs nuevos, modificados o eliminados
en esta carpeta. No hace falta ningun paso manual aparte de colocar los
archivos aqui.
